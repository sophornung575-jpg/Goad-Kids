📘 First-time setup (VB-Cable, keys, Live Producer)
  1. VB-Cable: download VB-CABLE Driver from vb-audio.com/Cable (free) → unzip → right-click VBCABLE_Setup_x64.exe → Run as administrator → Install Driver → restart the laptop.
  2. Khmer voice (CAMB.AI): in CAMB.AI Studio → Settings → API Keys → copy the key into CAMB.AI API key in the settings below → press Load voices → pick a voice → Test voice.
  3. Script writer (Google Gemini, free): aistudio.google.com → Get API key → Create API key → paste it into Gemini API key in the settings below.
  4. Script writer: nothing extra needed — it uses the same Gemini key (free tier). If you later want Claude to write instead, choose Claude in the settings and add a Claude API key from platform.claude.com (paid credit).
  5. Sound into the live: below, press Allow devices and set Send voice to = CABLE Input. In Facebook Live Producer (Chrome, same laptop) set Microphone = CABLE Output. Press Test tone — the Live Producer mic meter should move.
  6. Want to talk too? Tick Mix my microphone and pick your real mic (not CABLE).

Keys stay only in this browser on this laptop.
