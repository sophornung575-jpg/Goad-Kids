📘 First-time setup (VB-Cable, keys, Live Producer)
  1. VB-Cable: download VB-CABLE Driver from vb-audio.com/Cable (free) → unzip → right-click VBCABLE_Setup_x64.exe → Run as administrator → Install Driver → restart the laptop.
  2. Khmer voice key (Google Gemini): open aistudio.google.com and sign in with your Google account → Get API key → Create API key → copy it into Gemini API key in the settings below → press Test voice.
  3. Claude key: console.anthropic.com → API Keys → Create Key, and add a small credit (e.g. $5). Paste it below.
  4. Sound into the live: below, press Allow devices and set Send voice to = CABLE Input. In Facebook Live Producer (Chrome, same laptop) set Microphone = CABLE Output. Press Test tone — the Live Producer mic meter should move.
  5. Want to talk too? Tick Mix my microphone and pick your real mic (not CABLE).

Keys stay only in this browser on this laptop.
